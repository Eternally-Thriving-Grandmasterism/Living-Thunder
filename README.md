# Living Thunder

Static website for **Living Thunder**, the comic book and animated web series from AlphaProMega Media Inc. It is in development and production.

The site files live in `site/`. `.github/workflows/pages.yml` uploads only `site/` to GitHub Pages. For now the workflow runs only when someone starts it by hand. The repository owner switches GitHub Pages on in the repository settings (Source: GitHub Actions). There is no custom domain and no `CNAME`.
